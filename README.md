## 📈 Macroeconomic Framework & Core Metrics

This engine analyzes shifts in the sovereign debt market by isolating three core pillars of the fixed-income ecosystem:

*   **The 10Y-2Y Maturity Spread:** Tracks the yield differential between long-term and short-term debt obligations. A compressed or negative spread (inversion) serves as a premier leading indicator for macroeconomic recessions and banking Net Interest Margin (NIM) compression.
*   **Liquidity Preference Theory:** Models the term structure of interest rates to track how investor risk premiums shift during periods of monetary tightening versus market stabilization.
*   **Federal Reserve Policy Transmission:** Visualizes how aggressive changes in the federal funds target rate shift the short end of the curve, altering corporate capital allocation globally.

## 🚀 Local Implementation Guide

To run this data analytical engine locally, execute the following commands in your terminal environment:

```bash
# 1. Clone the repository framework
git clone https://github.com

# 2. Access the project root
cd The-US-Treasury-yield-curve

# 3. Install core dependencies
pip install -r requirements.txt

# 4. Initiate the local server
streamlit run app.py
```
